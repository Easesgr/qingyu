# 圆体字体

应用界面使用 Resource Han Rounded CN（资源圆体）0.990 的 Regular、Medium、Bold 三档，包括中文、拉丁字母和数字。字体随程序嵌入，用户无需安装；上下文共享只读字节，按实际使用的字符缓存字形。

原始发布地址：https://github.com/CyanoHao/Resource-Han-Rounded/releases/tag/v0.990

三个 TTF 文件直接从官方 `RHR-CN-0.990.7z` 解出，未修改或裁剪。来源、版本和 SHA-256 记录在 manifest.json。字体以 SIL Open Font License 1.1 授权，完整声明见 OFL-License.txt 与 LICENSE.md。少见字符和其他语言继续由系统字体补足。
