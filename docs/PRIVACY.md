# 轻屿数据说明

轻屿提供音乐、置物架、粘贴板、待办、邮箱、通知、天气、本机 Agent 监测和 Mac 状态。

- 任务、文件位置和设置保存在本机数据目录。
- 邮箱凭据保存在操作系统的安全凭据库；邮件内容从用户配置的 IMAP 服务读取。
- 聊天通知在用户启用并授予辅助功能权限后，读取所选客户端通过系统公开的通知预览与 Dock 未读标记，不登录 QQ 或微信，也不读取聊天数据库。内容预览由用户控制，轻屿不会主动展开系统通知中心。通知记录仅保留在本次运行的内存中，不上传；关闭接入或锁屏时暂停采集。详见 [通知接入说明](NOTIFICATIONS.md)。
- QQ 音乐通过系统 WebKit 显示官方网页，由用户自行登录，登录状态由 WebKit 保存；轻屿不读取账号密码、Cookie 或登录令牌。歌曲、歌单和进度等展示信息可缓存在本机。Apple Music / Spotify 信息来自本机播放器，播放控制受 macOS 自动化权限约束。
- 粘贴板单独记录复制的文字、图片与视频，媒体副本保存在本机数据目录的 `clipboard-media/` 中；原文件移动或删除后仍可再次复制。忽略密码管理器标记的敏感、临时和自动生成内容。关闭记录会暂停收集，清空保留固定条目，删除记录会清理对应的本机副本。
- 天气定位、城市搜索和 Open-Meteo 预报请求均忽略系统和环境代理。macOS 将天气连接绑定到 Wi-Fi / 以太网等物理网络的 IPv4 连接，并通过同一路径向 DNSPod 的 HTTPS DNS 服务解析天气域名，以避开 Clash 等 VPN 的 TUN 路由与 fake-IP DNS；直连失败时显示错误，不改用代理出口。
- 自动定位通过 ipwho.is 查询直连出口 IP 对应的大致城市，每次启动重新定位；天气服务和 DNS 服务会收到相应请求的出口 IP，不发送账号或其他应用数据。
- Agent 监测只在本机扫描进程、会话日志与标题元数据，提取 agent、对话名称、项目、工具名称和状态，不展示或保存对话正文及工具参数。详细状态集成只在用户点击安装时添加，保留已有 hooks / 插件配置；关闭 Agent 页面停止后台监测，移除集成会删除轻屿管理的条目。
- 各 Agent 的执行摘要与完成提醒短暂显示在岛内，不加入通知记录；Agent 页仅显示当前任务与一分钟内的新完成任务，轮次和去重状态仅保存在内存中。关闭相应提示或锁屏后停止展示，不集中重放期间完成的任务。岛内内容遵循通知预览设置，系统通知另受 macOS 授权与应用身份限制。
- Mac 状态仅通过本机 Mach、sysctl、IOKit 和系统网络接口读取 CPU、内存、磁盘、GPU 与网卡计数。指标与最近 1 分钟趋势只保存在内存中；关闭 Mac 状态页面或锁屏时暂停采集，不向 Stats 或其他服务发送监控数据。
- 应用不收集遥测，不上传任务、剪贴板或文件内容。

旧数据迁移保护现有内容。已删除的功能不再启动其后台服务或读取账号。诊断日志保存在本机，不自动上传。
