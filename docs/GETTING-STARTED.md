# 第一次使用轻屿

这份教程面向在自己 Mac 上安装轻屿的用户。你会使用自己的邮箱、音乐账号和本机 Agent；应用不会附带作者的账号、授权码、聊天记录或开发配置。

## 1. 我的 Mac 能不能运行

| 项目 | 当前情况 |
| --- | --- |
| 系统 | 构建最低目标为 macOS 12.0；不代表每个系统版本均已实测 |
| Apple Silicon（M 系列） | 选择文件名带 `macos-arm64` 的包；0.6.68 已在 macOS 15.7.3 / Apple Silicon 实机验证 |
| Intel | 需要单独的 `macos-x86_64` 包；已有构建入口，尚未完成 Intel 实机兼容验收 |
| 普通安装用户 | 不需要 Rust、Xcode、Node.js、图片生成服务或设计技能 |
| 详细 Agent 状态 | 另需自己的 Agent 和 Python 3；Hermes 使用其自身 Python 环境 |
| Hermes 整理拾光 | 可选，需自己的 Hermes、Python 3.10+ 及可用的模型／工具环境 |

在苹果菜单 →「关于本机」查看芯片和 macOS 版本。安装包内包含图标、字体、宠物素材和集成脚本，无须重新生成资源。

**当前分发状态：**[v0.6.68](https://github.com/Easesgr/qingyu/releases/tag/v0.6.68) 提供 Apple Silicon 预览包，采用 ad hoc 签名，尚无 Developer ID 与 Apple 公证，首次打开可能被 Gatekeeper 拦截。请按下节处理系统提示，或从[源码运行](MACOS.md#开发运行)。正式签名、公证流程见[发布指南](RELEASING.md)。

## 2. 安装与第一次打开

1. 在项目 GitHub 页的 **Releases** 中选取与你芯片匹配的版本。若尚无正式 Release，请先使用源码运行方式。
2. 下载该版本 ZIP 和对应的 `SHA256SUMS-macos-arm64.txt` 或 `SHA256SUMS-macos-x86_64.txt`。可在下载目录用 `shasum -a 256 -c 校验文件名` 核对完整性；校验和不能代替开发者签名。
3. 解压后，把完整的「轻屿.app」拖到「应用程序」，再从访达打开。不要只复制 `.app` 内的可执行文件。
4. 应用通常先显示屏幕边缘的岛和菜单栏图标。鼠标移到岛上会展开主控，点击右上角齿轮打开设置；也可从轻屿的菜单栏菜单打开设置，应用处于活动状态时可按 `⌘,`。
5. 在「功能编排」选择需要的模块，在「岛屿外观」调整显示器、位置、收起条长度和展开尺寸。
6. 需要开机自动运行时，在应用放到最终位置后，通过菜单栏菜单启用登录时启动。

若系统提示无法验证开发者，先确认下载来源、架构和发布说明。对可信且完整的下载，系统可能在「系统设置 → 隐私与安全性」提供「仍要打开」；macOS 12 对应「系统偏好设置 → 安全性与隐私」。若没有可用的允许入口、提示应用损坏或签名无效，请联系维护者或自行构建。不要全局关闭 Gatekeeper。

## 3. 我需要配置哪些内容

设置侧栏使用下面这些名称；括号内为功能含义。

| 设置入口 | 你需要准备 | 权限／网络 | 接通后的表现 |
| --- | --- | --- | --- |
| 暂存架（置物架） | 自己的本地文件 | 文件本身可访问 | 拖入后可打开原文件 |
| 剪贴簿（粘贴板） | 开启「记录复制内容」 | 系统剪贴板；不需要通知辅助功能权限 | 新复制的文字或图片出现 |
| 拾光／提醒清单 | 可直接手动记录 | 本机存储；Hermes 整理为可选 | 条目保存后重开仍存在 |
| 聆听（音乐） | QQ 音乐网页登录，或本机 Apple Music / Spotify | QQ 音乐需联网；控制本机播放器需自动化权限 | 歌名、进度与实际声音一致 |
| 信箱（邮箱） | 自己的邮箱地址和客户端授权码 | IMAP over TLS、系统钥匙串 | 账号显示「已连接」，能收到新邮件 |
| 消息（通知） | 选择来源；聊天客户端本身已登录 | 读取系统预览和 Dock 标记需辅助功能权限 | 收到一次真实的新消息提示 |
| 晴雨（天气） | 自动定位或选择城市 | 天气服务联网；不需要 API key | 城市、更新时间和实况正确 |
| 智能体（Agent） | 自己的本机 Codex / Claude Code / Hermes | 本机进程、会话日志及可选 hooks／插件 | 新任务执行时出现，完成后提醒一次 |
| 本机概览 | 无账号配置 | 本机系统指标 | CPU、内存等数值更新 |

权限按功能分别配置。邮箱收信不依赖辅助功能，QQ 音乐网页登录不等于聊天通知接入；只开基础功能也可以使用轻屿。

## 4. 接入音乐

### QQ 音乐

1. 打开「设置 → 聆听」，点击「打开我的音乐…」。
2. 在内置的 **QQ 音乐官方页面**用自己的账号登录。登录由 QQ 音乐处理，无须提供作者的账号或 API key。
3. 返回岛中的音乐页，打开「我的歌单」，必要时点击「刷新歌单」。
4. 选择一首可播放的歌曲，确认声音、歌名和进度对应；再分别测试暂停和继续。
5. 要彻底停止轻屿内的 QQ 音乐，使用「设置 → 聆听 → 停止 QQ 音乐」；仅关闭可见网页窗口不等于停止后台播放。

会员权益、地区与曲目可播放范围由 QQ 音乐决定。登录过期时重新打开官方页面登录即可。macOS 14+ 按轻屿数据目录隔离并持久保存 WebKit 登录环境；更换数据目录或服务端使登录失效后需重新登录。macOS 12/13 的存储差异见[音乐说明](MACOS.md#qq-音乐)。

### Apple Music / Spotify

先在这台 Mac 安装并打开播放器，播放一首歌曲，再到轻屿控制暂停或切歌。系统询问自动化权限时，按自己的意愿允许对应播放器；之后可在「隐私与安全性 → 自动化」检查。播放器没有提供当前曲目信息时，轻屿无法补出歌曲。

**确认接通：**听到的歌曲与轻屿显示一致，暂停后声音停止。如果有两个声音，先停掉其他播放器，再用「停止 QQ 音乐」关闭轻屿的后台播放，最后只从一个入口重新播放。

## 5. 接入邮箱

### 准备账号

先在邮箱服务自己的网页设置中开启 IMAP，并生成客户端授权码／应用专用密码。**填写客户端授权码，不填普通网页登录密码。**

| 邮箱服务 | 准备方式 |
| --- | --- |
| QQ 邮箱 | 在 [QQ 邮箱](https://mail.qq.com/)设置中开启 IMAP，生成授权码 |
| 163 / 126 | 在 [163](https://mail.163.com/) 或 [126](https://mail.126.com/)邮箱开启 IMAP，获取客户端授权密码 |
| 腾讯企业邮 | 在[企业邮](https://exmail.qq.com/)按企业策略开启 IMAP／客户端专用密码；可能需要管理员允许 |
| iCloud | 在 [Apple 账户](https://account.apple.com/)生成 App 专用密码；需满足 Apple 的账号安全要求 |
| Gmail | 在 [Google 账户](https://myaccount.google.com/apppasswords)生成应用专用密码；需开启两步验证且账号／组织策略允许 |
| 其他单位／学校邮箱 | 向管理员索取 IMAP TLS 主机、端口、登录用户名和允许使用的客户端密码 |

Outlook、Hotmail、Live 和 Microsoft 365 云邮箱所需的 OAuth 目前尚未接入。自定义邮箱只支持 **IMAP over TLS**（常见端口 993），不支持 STARTTLS、OAuth2 或企业 SSO；不能仅更换主机名就绕过服务端认证要求。

### 在轻屿添加

1. 打开「设置 → 信箱」，在「添加邮箱」选择服务商。
2. 填写完整邮箱地址和授权码。自定义服务另外填写「IMAP 主机」「TLS 端口」「登录用户名」；用户名留空时使用邮箱地址。
3. 点击「测试连接」，等待成功结果。
4. 点击「保存并开始监控」。只测试连接不会把账号保存到监测列表。
5. 确认「已添加的邮箱」中账号已启用，状态为「已连接」；需要提醒时开启「新邮件提醒」和「设置 → 消息 → 接收通知」。
6. 从另一邮箱给自己发一封新测试邮件，检查邮件页和岛内提醒。首次载入的历史邮件保持静默，不能用旧邮件判断新邮件提醒是否接通。

授权码保存在**当前 Mac 用户的系统钥匙串**，账号清单保存在轻屿数据目录。复制账号清单不能迁移授权码。换机、授权码撤销或钥匙串拒绝访问时，在新电脑重新添加／测试账号；不要把授权码提交到仓库或公开 Issue。

「同步邮件操作到邮箱」默认关闭，此时操作只影响轻屿。开启后，后续已读、删除和恢复操作会同步到邮箱；开启前的本机操作不会补发。

## 6. 接入 QQ、微信等聊天通知

1. 先在这台 Mac 登录需要监测的 QQ、微信等客户端。
2. 在 macOS 的通知设置和客户端自己的设置中，开启该客户端的通知、内容预览及需要的 Dock 未读标记。
3. 打开轻屿「设置 → 消息」，开启「接收通知」「启用系统通知监测」，选择需要的来源；是否开启「显示内容预览」由你决定。
4. 点击「打开辅助功能设置…」，为**最终安装位置的轻屿.app**开启辅助功能权限。macOS 13+ 位于「系统设置 → 隐私与安全性 → 辅助功能」；macOS 12 位于「系统偏好设置 → 安全性与隐私 → 隐私 → 辅助功能」。
5. 回到轻屿检查接入状态，等待它建立当前未读基线，再让联系人发一条新消息。测试系统横幅时，让来源客户端处于后台，并确认专注模式等没有隐藏横幅。

**确认接通：**岛下方出现该来源的新提示。采集到系统预览时可显示发送者和正文；只有 Dock 未读变化时显示通用未读提示。设置里的本地测试提示仅验证岛的显示，不能证明微信或 QQ 已接通。

macOS 没有通用的第三方通知订阅公开接口。轻屿读取系统通过辅助功能公开的预览和 Dock 标记，不读取聊天数据库，也不能保证捕获每条消息或精确打开对应会话。隐藏预览、专注模式、客户端行为和系统版本都可能影响结果。首次连接与解锁不会重放已有未读。

如果换过应用路径或签名，旧权限可能不匹配：先核对正在运行的是哪一份轻屿，必要时在辅助功能列表移除旧条目，再添加最终位置的应用。终端诊断显示有权限，并不能证明从访达打开的 GUI 实例也有权限。详细排查见[通知说明](NOTIFICATIONS.md)。

## 7. 接入 Codex、Claude Code 和 Hermes

这些状态来自**这台 Mac**的真实任务。轻屿不登录你的 Agent 账号，不替你配置模型或 API key，也不会自动监测另一台电脑或云端任务。

1. 先按对应 Agent 的官方说明完成安装、登录／模型配置，并在本机正常运行一次，让它创建自己的配置目录。
2. 确认 Python 3 可用；Codex / Claude 状态脚本需要它，Hermes 插件使用 Hermes 环境。只看见进程不代表完整任务状态与标题读取均可用。
3. 在轻屿「功能编排」启用智能体，在「设置 → 智能体」点击「安装状态集成」；已有安装时按钮为「修复状态集成」。查看每个 Agent 的安装结果。
4. 安装操作不会打断正在运行的任务。先结束当前工作，再新开会话或安全重启对应 Agent，使新 hooks／插件生效。
5. 需要岛上提示时，在「智能体 → 岛内提醒」开启「开始与中断提醒」「任务完成提醒」，并在「消息」开启「接收通知」。
6. 启动一次短任务，执行期间查看主控／智能体页，结束后确认只出现一次完成提醒。设置中应从「集成已安装」变为「已收到任务状态」。

可在终端用 `python3 --version` 检查 Python。若不可用，可从 [Python 官网](https://www.python.org/downloads/macos/)安装当前受支持的 Python 3，再重开轻屿并修复状态集成；无需把维护者电脑的 Python 路径复制到自己的配置。

| Agent | 当前能力 |
| --- | --- |
| Codex | 本机进程和会话日志识别；状态集成补充真实任务事件 |
| Claude Code | 本机会话日志及状态 hooks |
| Hermes | 进程识别；详细执行／等待／完成状态需安装插件 |
| Gemini CLI / OpenCode / Cursor Agent / Aider | 当前主要为进程识别，尚无同等完整的任务状态与完成提醒适配 |

空闲应用不显示为执行中。历史完成任务不在启动时补发；刚完成的任务在列表保留 1 分钟后消失。这些情况均不表示连接失败。审批只在岛上提示，仍需回到原 Agent 应用操作。

集成使用当前用户的配置目录，保留原 hooks／插件；相关修改的备份位于 Agent 配置目录的 `.qingyu-backups`。更换轻屿数据目录、电脑或 Agent 目录后，重新安装／修复集成。移除方式与细节见[Agent 监测说明](AGENT-MONITOR.md)。

### 使用自定义 Agent 目录

默认读取 `~/.codex`、`~/.claude` 和 `~/.hermes`，分别支持 `CODEX_HOME`、`CLAUDE_CONFIG_DIR`、`HERMES_HOME`。**从访达打开的应用通常不会继承 `.zshrc` 里的变量**，因此终端中的 Agent 可用，不代表轻屿看到了同一目录。

若使用自定义目录，先退出已运行的轻屿，再从终端带上真实目录启动。例如只自定义 Codex：

```sh
# 把 /absolute/path/to/codex-home 替换成自己实际使用的绝对路径。
CODEX_HOME="/absolute/path/to/codex-home" \
  "/Applications/轻屿.app/Contents/MacOS/qingyu"
```

其他两个变量同理；轻屿和对应 Agent 必须指向同一份目录，再从设置修复集成。示例变量只对这次启动有效，不会替你配置访达启动或登录启动环境。

## 8. 拾光、暂存架、剪贴簿与天气

### 拾光与提醒清单

手动记录不需要安装 Hermes。在「设置 → 拾光」点击「打开拾光」或「打开提醒清单」即可使用。

如果需要 Hermes 帮忙整理：

1. 先让自己本机的 Hermes 能正常执行任务，并确认 Python 3.10+ 可用。
2. 在「设置 → 拾光」点击「安装 Hermes 整理能力」，已有安装时用「检查 / 更新整理能力」。
3. 在自己的 Hermes 会话中加载 `qingyu-shiguang`，明确要求收藏一条测试内容，并确认轻屿中出现该条目。
4. 若通过微信收藏，还需要你自己接好 **微信 → Hermes 网关**，并在那个微信会话加载技能；轻屿不会安装网关或替你扫码登录。CLI 收藏成功只证明本机通道正常。

安装会绑定本机轻屿资料库的绝对路径。换机或更改数据目录后，重新检查／更新整理能力；不要复制作者机器的技能配置。完整步骤见[拾光说明](SHIGUANG.md)。

### 暂存架与剪贴簿

把一个本地文件拖入暂存架，再点击打开，确认文件可访问。暂存架保存的是路径，**不会复制原文件**；原文件移动、外置盘断开或换机后可能需要重新添加。

在「设置 → 剪贴簿」开启「记录复制内容」，复制一段测试文字或图片，确认新记录出现并能再次复制。图片／视频副本保存在本机数据目录；密码管理器标记为敏感等内容会跳过。关闭记录后停止采集，细节见[剪贴簿说明](MACCY.md)。

### 天气与本机概览

在「设置 → 晴雨」使用自动城市或搜索并选择自己的城市，检查实况与更新时间。天气无需填写 API key；自动城市基于出口 IP 的大致位置，并非 GPS。天气请求走直连物理网络，网络限制、VPN 或位置误判时可先手选城市并重试，见[数据说明](PRIVACY.md)。

本机概览无需账号；启用后查看 CPU、内存等数值是否更新。关闭模块或锁屏时暂停采样。

## 9. 升级、备份与换机

默认用户数据位于：

```text
~/Library/Application Support/Qingyu/
```

在访达按 `⇧⌘G` 输入这个路径即可打开。开发者可用 `QINGYU_DATA_DIR` 指定独立目录；普通安装用户无需设置它。不要把作者的 `.dev-data/` 当作首次运行配置分发。

| 内容 | 换机时怎么处理 |
| --- | --- |
| 本机设置、拾光、提醒清单、剪贴簿与媒体 | 退出轻屿后私下备份数据目录；在新机首次启动前恢复到自己的数据目录 |
| 邮箱授权码 | 在新机重新添加／授权；数据目录中的账号清单不包含可迁移的密码 |
| QQ 音乐网页登录 | 在新机的官方页面重新登录；不要手动复制 Cookie 或令牌 |
| 辅助功能、自动化、登录启动 | 在新机按实际安装路径重新配置 |
| Agent hooks／插件、拾光整理技能 | 在新机安装 Agent 后，从轻屿重新安装／修复，更新绝对路径 |
| 暂存架 | 先迁移原文件，再重新添加路径已变化的条目 |
| 通知记录和近期 Agent 状态 | 仅保存在本次运行内存中，不随备份迁移 |

升级时先退出旧版，再替换「应用程序」中的 `.app`；保留用户数据目录。保持同一发布者签名与应用标识有助于延续系统授权，但开发签名切换到正式签名时仍可能需要重新允许权限或测试邮箱。恢复个人备份前先备份新机现有数据，避免直接覆盖。

## 10. 常见问题

| 现象 | 先检查 |
| --- | --- |
| 启动后没有普通主窗口 | 查找边缘岛与菜单栏图标，从菜单打开设置；在「岛屿外观」选择当前显示器 |
| 下载后被 macOS 拦截 | 架构、完整性和发布签名；当前开发包不等于已公证包，见第 1、2 节 |
| 邮箱测试成功但没有监控 | 是否点击「保存并开始监控」，账号与新邮件提醒是否启用 |
| 邮箱认证失败 | 是否启用 IMAP，是否使用授权码，账号是否受 OAuth／组织策略限制 |
| 微信只有未读数，没有正文 | 系统是否公开预览；辅助功能权限不能补出系统隐藏的正文 |
| 通知测试能显示但收不到微信 | 测试提示只验证 UI；按第 6 节检查真实新通知、来源和 GUI 权限 |
| Agent 显示「未发现应用」 | 先运行对应 Agent；检查默认／自定义目录与 Finder 环境差异 |
| Agent 只有「集成已安装」 | Python 环境、会话是否加载新集成，以及安装后是否真正执行了新任务 |
| Agent 打开着但任务列表为空 | 空闲进程不等于执行任务；已完成超过 1 分钟的任务会移除 |
| 音乐没声音或歌单不完整 | 官方页面登录、会员／地区、网络及歌曲实际可播放性 |
| 天气城市不对或一直加载失败 | 手选城市、直连网络和服务可达性 |
