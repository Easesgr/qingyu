# 轻屿 v0.6.68 · macOS 预览版

首次公开源码与下载，当前提供 **Apple Silicon（M 系列）** 安装包。

## 下载与安装

1. 下载 `Qingyu-v0.6.68-macos-arm64.zip` 和 `SHA256SUMS-macos-arm64.txt`。
2. 在下载目录运行 `shasum -a 256 -c SHA256SUMS-macos-arm64.txt`。
3. 解压，将完整的「轻屿.app」移到「应用程序」，从访达打开。

**这是未经过 Apple 公证的 ad hoc 签名预览包。** 首次打开可能被 Gatekeeper 拦截；确认来源与校验和后，按「系统设置 → 隐私与安全性」提供的「仍要打开」操作。系统没有允许入口或提示签名损坏时，请反馈或从源码运行，不要全局关闭系统安全保护。

最低构建目标为 macOS 12.0；已在 macOS 15.7.3 / Apple Silicon 验证。Intel 和其他系统版本尚未完成实机验收，本次不提供对应二进制包。

## 功能

- 音乐、置物架、剪贴簿、拾光与提醒清单、邮箱、通知、天气、Agent、Mac 状态及主控总览。
- 自由位置、左右吸附、多屏、独立收起条长度、面板尺寸、悬停切页与钉住。
- 五种皮肤、七种宠物、Agent 头像绑定与单行通知。
- Codex / Claude Code / Hermes 真实任务状态与完成提醒。

## 首次接入

安装包不含私人账号、授权码或开发配置。音乐、邮箱、通知权限及 Agent 集成由每位用户自行接入：

- [安装与接入教程](https://github.com/Easesgr/qingyu/blob/main/docs/GETTING-STARTED.md)
- [功能与实际截图](https://github.com/Easesgr/qingyu#readme)
- [源码与构建](https://github.com/Easesgr/qingyu/blob/main/CONTRIBUTING.md)

邮箱目前不支持 Microsoft 云邮箱 OAuth；聊天通知取决于系统公开的预览与 Dock 标记；Agent 监测仅针对本机。完整限制见 README 与接入教程。
